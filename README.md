# L’effet papillon — site web

Site vitrine du salon **L’effet papillon** (extensions de cils & tatouage de sourcils, Mamoudzou, Mayotte).

## Fichiers
- `index.html` — contenu du site (accueil, prestations & tarifs, galerie, contact)
- `style.css` — mise en forme
- `script.js` — menu mobile et agrandissement des photos
- `images/` — vos photos

## Personnaliser
- **Tarifs** : modifiez les lignes `<li>` de la section « Prestations » dans `index.html`.
- **Photos** : déposez vos photos dans `images/` sous les noms `galerie-1.jpg` à `galerie-9.jpg` (format carré conseillé). Tant qu’une photo manque, un fond décoratif s’affiche.
- **Réservation** : tous les boutons « Réserver » mènent vers https://Leffetpapillon976.as.me/

## Mettre en ligne
Le site est 100 % statique : il peut être publié gratuitement avec GitHub Pages
(Settings → Pages → branche principale, dossier racine).
